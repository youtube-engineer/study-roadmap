# プロトタイプ

編集画面と共有ページの動作プロトタイプ。**本実装ではない。**
dnd-kitの挙動、タッチ操作の制約、画面構成の検証用。

```bash
pnpm install
pnpm build
# dist/index.html をブラウザで開く（スマホでも確認すること）
```

上部のタブで「自分の編集画面」と「他人の共有ページ」を切り替えられる。

## 触って確認できること

- カード右端の握りをつまんで並び替え（押した瞬間から動く）
- カードをタップで詳細シート（終了の切替・周回の目標・メモ・削除）
- 番号の点をタップで終了の印。その区間の紐が濃くなる
- 経路上の「参考書を追加」から検索シート。追加済みの本はグレーアウト
- 共有シート（公開トグル・URLコピー・SNSでの見え方）
- 共有ページから「このルートをコピーして使う」→ 自分の編集画面に入る。
  順番・メモ・周回は引き継ぎ、終了の印は引き継がない。複製元の表示が出る

## 移植時に見るべき箇所

- `src/App.jsx` の `RoadmapSensor`
  — dnd-kitのセンサーを1つにまとめ、押された位置で発火条件を切り替える実装。
  センサーを2つ登録すると後勝ちで上書きされて無言で壊れるため（`CLAUDE.md` 9章）
- `index.html` の `.card` と `.handle` の `touch-action`
  — 掴める範囲とスクロールが両立しない制約への対処（同上）
- `index.html` の `:root` / `@media (prefers-color-scheme: dark)` / `:root[data-theme="dark"]`
  — ライト/ダーク両対応のトークン設計
